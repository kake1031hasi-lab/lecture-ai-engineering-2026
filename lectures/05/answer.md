## 宿題

- 取り組んだレベル：発展
- やったこと（変更したファイル・設定・処理、または設計した取得方法）：
  - 変更ファイル：`app/retrieval.py`（`search_graph` 関数）
  - 変更内容：従来の `search_graph` はベクトル検索の類似度上位 `GRAPH_START_K`（3件）をそのまま探索の入口（`seeds`）としていたため、複数の講義回（新旧の資料）をまたぐ質問において特定の講義回にシードが偏り、別講義の関連ページが押し出される課題があった。そこで、ベクトル検索のヒット候補から**異なる講義回（`document_id`）ごとに最上位のページを優先して1件ずつシードに確保し、残りの枠をスコア順で埋める（Cross-Document Seeding）**ロジックへ改良した。
- 比較した質問と、固定した条件（モデル・対象資料など）：
  - 質問：`第2回で説明された『FTでは知識が入りにくくRAGが効きやすい理由』と、第3回で学ぶ『エージェントに外部ツールを持たせる仕組み』を組み合わせると、なぜ複雑な質問に答えられるようになりますか？`
  - 固定条件：モデル `gemini-3.1-flash-lite`、対象資料は第1〜3回講義資料（214ページ、`index.sqlite3` / `graph.json`）、グラフ設定（`GRAPH_START_K=3`, `GRAPH_MAX_HOPS=2`, `GRAPH_MAX_RESULTS=8`）。
- 結果（変更前後の回答・根拠、`--trace`の出力、時間・トークン数・生成API推定費用など）：
  - **検索器単体（`search_graph`）の変更前後の比較：**
    - 変更前の `seeds`：1位 第3回 p.10（ツール）、2位 第3回 p.3（第2回で見たモデルの性質〜）、3位 第2回 p.46（小規模なFTは振る舞いに強く〜）。第3回に2枠偏ったため、第3回 p.3 の隣接ページである「第3回 p.2 自己紹介」「第3回 p.4 アジェンダ」が `expanded` の3〜4位に混入し、第2回の核心ページ「第2回 p.45」「第2回 p.47（根拠と諸説：知識の追加はRAGが効きやすい）」は5〜6位に押し下げられていた。
    - 変更後の `seeds`：1位 第3回 p.10（ツール）、**2位 第2回 p.46（小規模なFTは振る舞いに強く〜）**、3位 第3回 p.3。講義回ごとのシード確保により第2回 p.46 の優先度が上がり、その結果 `expanded` でも**「第2回 p.45」「第2回 p.47」が3位・4位に上昇**し、ノイズページより上位で安定して取得できるようになった。
  - **エージェント実行結果（変更後・`gemini-3.1-flash-lite`）：**
    - 回答要点：第2回 p.46-47, 53（FTとRAGの役割分担）と第3回 p.10-12（ツール利用とループ構造）の両方を正確に統合し、複雑な質問に答えられる理由を3点に構造化して回答。
    - `--trace` 出力：`search_graph` を2回呼び出し（`query='FT RAG 知識 理由 第2回'`, `query='エージェント 外部ツール 第3回'`）。
    - 時間・トークン・費用：5.17秒 / 入力 9,288 tokens / 出力 669 tokens / モデル応答 2回 / 推定コスト $0.003326 USD。
- 改善した例と、残る失敗・制約：
  - 改善した例：複数の講義回（旧講義の基礎知識と新講義の設計知識）を横断するクエリにおいて、片方の講義回にシードが偏って関連ページが下位に埋もれる現象を抑制し、両講義の根拠ページをバランスよく上位に引き上げることができた。
  - 残る失敗・制約：隣接エッジ（`next_page`）を無条件に1ホップ展開する仕組み自体はそのままのため、「第3回 p.3」がシードに入った際に隣接する「p.2 自己紹介」「p.4 アジェンダ」といった形式的なスライドまでグラフ展開候補に残る制約がある。また、今回は同じ講義資料内の複数回で検証したが、実務の「同一テーマで仕様が改訂された新旧ドキュメント（例：旧版マニュアルと最新版マニュアル）」へ応用する場合は、単純な並列分散だけでなく`lecture`番号や更新日時メタデータを用いた新旧の優先度・矛盾解消ルールの組み合わせが必要になる。
- 気づき・疑問：
  - RAGの検索精度向上は埋め込みモデルの変更だけでなく、「シードの多様性確保（ドキュメント分散）」のようなグラフ探索の入口設計を数行工夫するだけでも、後続のホップ展開の質と根拠の網羅性を大きく改善できると実感した。
